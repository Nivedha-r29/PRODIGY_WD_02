# PRODIGY_WD_02

## Nivedha Stopwatch Pro

A modern and interactive stopwatch web application built using HTML, CSS, and JavaScript as part of the Prodigy InfoTech Web Development Internship.

### Features

* Start Stopwatch
* Pause Stopwatch
* Reset Stopwatch
* Lap Time Recording
* Neon Glow Interface
* Glassmorphism Design
* Animated Background Particles
* Responsive Layout

### Technologies Used

* HTML5
* CSS3
* JavaScript
